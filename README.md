# Torres Motos Analytics

Pipeline ETL e Analytics para o setor de varejo de motocicletas, desenvolvido para centralizar dados de vendas, clientes, frotas e manutenções.

## 🚀 Tecnologias Utilizadas
- Python (Pandas, SQLAlchemy)
- SQL (PostgreSQL / Modelagem Relacional)
- Git & GitHub
- Power BI / Streamlit (Visualização de Dados)

## 📁 Estrutura do Projeto
- `data/`: Armazenamento de dados brutos (`raw`) e processados (`processed`).
- `src/`: Código fonte dividido em configuração (`config`), etl (`etl`) e aplicação (`app`).
- `docs/`: Modelagem de banco de dados (`schema.sql`) e massa de dados inicial (`seed.sql`).

## 📊 Arquitetura e Diferenciais
- Modelagem relacional normalizada para integridade de dados.
- Pipeline ETL modular em Python para ingestão automatizada.
- Indicadores de desempenho (KPIs) voltados para conversão de vendas e retenção pós-venda.
